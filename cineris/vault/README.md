# Хранилище писем (Vault) — как включить по-настоящему

Сейчас на сайте хранилище работает в демо-режиме: письмо хранится только в браузере того, кто его запечатал, и сайт честно об этом пишет. Чтобы письма хранились на сервере и открывались у получателя в назначенный день:

1. **Supabase (бесплатно):** зарегистрироваться на https://supabase.com и создать проект (регион — US West).
2. **Таблицы:** SQL Editor → New query → вставить `schema.sql` → Run.
3. **Функция:** установить Supabase CLI (`npm i -g supabase`), затем в этой папке:
   ```
   supabase login
   supabase link --project-ref <ID проекта>
   supabase functions deploy vault --no-verify-jwt
   supabase secrets set SITE_ORIGIN=https://thethree.jewelry
   ```
   (Или попросите Claude сделать это с ноутбука — нужен будет доступ к проекту.)
4. **Сайт:** в `site/site.config.mjs` вписать
   `vaultApi: 'https://<ID проекта>.supabase.co/functions/v1/vault'`, пересобрать сайт.
5. **Коды:** когда заказ оплачен, добавить код в таблицу `codes` (пример внизу `schema.sql`), выгравировать его у замка и отправить клиенту.

**Как это работает:** письмо можно запечатать один раз; изменить нельзя; открыть — только в день, который выбрал отправитель (не дальше чем через год). Фото и видео лежат в закрытом хранилище и выдаются по временной ссылке только после этого дня.

**Позже можно добавить:** письмо-уведомление получателю в день открытия (поле `notify_email` уже сохраняется), ограничение попыток ввода кода.
